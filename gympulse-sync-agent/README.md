# GymPulse Sync Agent

Biometric attendance sync agent for Windows. Connects biometric devices to Firestore.

## Quick Start

```bash
cd gympulse-sync-agent
npm install
npm start
```

## Build Windows EXE

```bash
npm run build:win
```

Output: `dist/` folder with installer.

## Configuration

Edit `config/default.json` or use the in-app Settings panel.
